# No AI Slop — Canonical Technical Prose Standard

- Write direct, concise, evidence-backed technical prose.
- Eliminate throat-clearing introductions, sycophantic filler, and cliché transitions (`delve`, `leverage`, `robust`, `tapestry`, `paramount`, `seamless`).
- Present concrete file paths, diffs, commands, and verification evidence directly.
