# Apex Harness — Remaining Production Gaps & Non-Blocking Operational Items

**Audit Commit Baseline:** `97b7b7e` (plus final production-readiness surgical fixes)

During the Final Production Readiness Audit, **5 code-level defects** were discovered via live provider/CLI probing and source inspection and were **fixed and verified (`VERIFIED` / `UNIT-VERIFIED`) in this audit**:

1. **FIXED (`server/harness/driver-registry.ts`):** `HttpProtocolDriver.streamEvents()` previously buffered the entire HTTP response before emitting `delta` events and declared `supportsSubagents: true`. Fixed to stream `res.body.getReader()` SSE chunks incrementally as they arrive and report `supportsSubagents: false`.
2. **FIXED (`server/harness/driver-registry.ts`, `server/harness/protocol-adapters.ts`):** `NativeCliHarnessDriver` on Windows previously resolved extensionless POSIX shims or `.cmd` wrappers without extracting the target `.exe`/`.js` entrypoint, clobbered `HOME`/`USERPROFILE` for non-Carbon models, and passed `--resume <localSessionId>` instead of the CLI's native session ID (`thread_id` / `session_id` / `sessionID`). Fixed and verified live with `codex-cli 0.164.0` Turn 1 + Turn 2 native session resumption.
3. **FIXED (`server/harness/egm-boardroom.ts`):** `runPostImplementationEgmReview()` previously called `JSON.parse(rawContent)` without stripping `<think>...</think>` or ` ```json ` markdown fences returned by real reasoning LLMs, used an 8s timeout that was too short for thinking models, and did not scrub secrets from `changedFilesContent` / `gitDiffSummary` before sending to the external Goldfish reviewer. Fixed and verified live against `gemini-3.8-flash-high` (`http://127.0.0.1:8765/v1/chat/completions`).
4. **FIXED (`server/harness/completion-evidence.ts`, `server/harness/agent-dag-orchestrator.ts`):** `detectProjectVerificationCommands()` previously hardcoded `npm`, did not ignore default `npm init` `"no test specified"` placeholder scripts, did not inspect monorepo workspaces (`pnpm-workspace.yaml` / `workspaces`), omitted `buildCommands` from `node-verifier`'s `autoQueue`, and assigned a single global status to all clauses in `requirementMatrix`. Fixed and verified across all 7 repository archetypes in `V-10`.
5. **FIXED (`package.json`, `electron/apex-main.mjs`, `ui/agent-office.js`):** Aligned `package.json` `"main"` with `electron-builder.apex.yml` (`electron/apex-main.mjs`, preserving `--openmausbot` / `OMB_DESKTOP=1` delegation to `electron/main.mjs`), configured `ApexHarness` app identity, and updated `ui/agent-office.js` + `agent-dag-orchestrator.ts` so deterministic scans display `DETERMINISTIC SCAN` rather than an AI model name.
